# 완성본 시연 순서와 정리 (케셰브 · 신영한)

이 문서는 만든 기능을 한 번에 보여 주기 위한 정리입니다. 상세 설명은 `docs/RUN_GUIDE.md`(실행 안내)와 `docs/STUDENT_DASHBOARD.md`(대시보드)를 보세요. 이 문서는 새 코드나 기존 문서를 바꾸지 않습니다.

- 화면 틀: 관제 대시보드형(맨 위 상태 카드 4개, 아래 추이와 기록)
- 실행 형태: 포장 없이 내 PC에서 실행. 포장 명령(`npm run package-app`)은 실행하지 않았습니다.
- 작업 폴더 `on-client-pcstatus`, 브랜치 `pc-status`. 이미 낸 제출물(`37995f6`)과 `master`는 건드리지 않았습니다.
- 이 문서가 기준으로 삼은 마지막 커밋은 `78ce80c`입니다. 이 문서를 추가하는 커밋은 포함하지 않습니다.

## 2. 핵심 기능 3가지와 시연 순서

### 준비

1. PowerShell에서 작업 폴더 `<내 PC의 작업 폴더>\on-client-pcstatus`로 이동합니다.
2. 이미 켜 둔 서버가 있으면 끕니다(새 코드로 켜야 새 화면이 나옵니다). 방법은 `docs/RUN_GUIDE.md` 6장을 따릅니다.
3. `.\tools\start-alekov.ps1`로 켭니다(또는 `npm start`).
4. 브라우저(Chrome)에서 `http://127.0.0.1:5189/`를 열고 「보호 현황」 탭을 엽니다.

시작 도구로 켜기와 `npm start` 모두 [직접 확인]. 이 시연에서 화면의 숫자는 모두 `[예시 값]`으로 적었습니다.

### 시연 ① PC 상태 실측 (CPU·메모리·디스크)

보조 기능: CPU 막대 그래프, 직전 조회 대비 한 줄, 새로고침 후 기록 유지, 「기록 지우기」

| 단계 | 누를 것 | 기대 화면 | 확인 |
|---|---|---|---|
| 1 | 아직 아무것도 누르지 않음 | 카드 4개(CPU·메모리·디스크·방화벽)가 모두 `조회 전`, 「PC 상태 조회」 버튼은 한 곳 | [AI 확인] 실제 Chrome / [직접 확인] |
| 2 | Tab으로 「PC 상태 조회」에 이동해 Enter(또는 클릭) | `조회 중…` 뒤 `[예시 값] 14:02 조회 성공`. 카드에 CPU %, 메모리 %, 디스크 GiB, 방화벽 `켜짐/꺼짐`과 작은 `[실제 측정]` 표시 | [AI 확인] / [직접 확인] |
| 3 | 「다시 조회」를 두세 번 | CPU 막대가 하나씩 늘고 막대 아래에 숫자. `직전보다 ▲ [예시 값] +9.5 %p 증가` 한 줄(▼ 감소, = 같음) | [AI 확인] / [직접 확인] |
| 4 | 막대에 마우스를 올림 | 시각과 CPU 값이 나옴 | [AI 확인] / [직접 확인] |
| 5 | 새로고침(F5) | 카드는 `조회 전`으로 돌아가고 막대는 저장된 기록으로 그대로 남음 | [AI 확인] / [직접 확인] |
| 6 | 「자세히」를 열고 「기록 지우기」 | 막대가 사라지고 "비교할 이전 조회가 없습니다" | [AI 확인] / [직접 확인] |

메모리 `%`는 (전체−여유)÷전체로 계산한 값이며 카드에는 `사용(계산값)`으로 적힙니다. [AI 확인]

### 시연 ② 네트워크·방화벽·Windows 기록 건수 읽기

읽기 전용입니다. 못 읽은 항목은 값을 만들지 않고 `확인 불가`로 표시합니다.

| 단계 | 누를 것 | 기대 화면 | 확인 |
|---|---|---|---|
| 1 | 시연 ① 2단계의 조회 결과 아래를 봄 | 한 줄 요약: `네트워크 물리 [예시 값] 1개 연결됨 · Windows 오류 [예시 값] 5·경고 [예시 값] 11(최근 24시간)` | [AI 확인] / [직접 확인] |
| 2 | 요약 아래 문구를 읽음 | 「이 건수는 침해나 공격 탐지 결과가 아닙니다.」와 `SDP 미연결` | [AI 확인] / [직접 확인] |
| 3 | 방화벽 카드를 봄 | 프로필이 모두 같으면 `모두 켜짐` 또는 `모두 꺼짐`, 다르면 프로필별 글자 | [AI 확인] 가짜 화면 점검. 실제 Chrome에서 `모두 켜짐` / [직접 확인](카드 4개 값) |
| 4 | 「자세히」를 엶 | 어댑터별 · 방화벽 프로필별 · System/Application 건수 · 기록 건수 · 한계 문장 | [AI 확인] / [직접 확인](열기) |

- 오류·경고 건수는 침해나 공격을 탐지한 결과가 아닙니다. 건수만 보여 줍니다.
- 이 앱은 설정을 바꾸지 않고 관리자 권한을 쓰지 않습니다. 읽기 전용 허용 목록의 PowerShell 명령만 거칩니다. [소스 확인] / 점검 도구의 자체 점검 통과 [AI 확인]

### 시연 ③ 다시 조회와 오류 화면 (서버를 끈 실패 화면 포함)

| 단계 | 누를 것 | 기대 화면 | 확인 |
|---|---|---|---|
| 1 | 「다시 조회」 | 상태 줄이 `조회 중…` 뒤 `[예시 값] 14:05 다시 조회 성공`. 버튼 초점이 그대로 남음 | [AI 확인] / [직접 확인] |
| 2 | 서버 창에서 Ctrl+C로 서버를 끔 | (서버 중지) | [직접 확인](끄는 법) |
| 3 | 「다시 조회」 | `조회 실패`. 카드 4개는 모두 `확인 불가`와 이유가 나오고 숫자는 없음. 요약도 `확인 불가`, SDP도 `확인 불가`(`미연결`이 아님). 「핵심 3가지」 패널에 항목별 이유와 「다음에 할 일」 | [AI 확인] / [직접 확인] |
| 4 | 서버를 다시 켜고 「다시 조회」 | 다시 값이 채워짐 | [직접 확인](확인 후 서버를 다시 켬) |

실패한 조회는 그래프에서 빼고 안내만 보여 줍니다. [AI 확인]

## 5. 한계

### 5-1. 약속한 한계

- 이 앱은 완성된 보안 제품이 아니라, 내 PC 상태를 읽어서 숫자와 변화를 보여 주는 학습용 모니터링 앱입니다. 침해나 공격을 탐지하거나 막지 않습니다.
- **SDP 서버는 실제로 연결되지 않습니다**(발급 인증서 없음). 화면의 SDP 칸은 `SDP 미연결`로 표시되고, 조회가 실패했을 때는 `확인 불가`로 씁니다. 조회 중에 SDP 서버에 접속하지 않습니다. [소스 확인] 화면 표시는 [AI 확인]과 [직접 확인]
- **제공 파일 `src/server.mjs`를 12줄 수정했습니다**(라우트 `/api/pc-snapshot` 1개). 설치형 앱에는 이 경로가 없을 수 있고, 그 경우 화면은 `확인 불가`로 표시됩니다. 설치형 앱에서의 동작은 [미확인]입니다.
- **`student/appearance.json`은 이 시작 틀(0.2.11)에 읽는 코드가 없어 쓰지 않았습니다.** 파일도 없고 `src`·`student`·`public`에서 읽는 코드를 찾지 못했습니다. [AI 확인]
- **메모리·디스크·방화벽의 이전 조회 값은 저장되지만 화면에서는 보이지 않습니다.** 화면의 그래프는 CPU 사용률만 그립니다. [소스 확인] / [AI 확인]
- **포털 예시의 세 단계 상태 판정(상태 이름을 붙여 나누는 방식)은 근거 없는 임계값이라 따라 하지 않았습니다.** 화면에는 숫자와 변화(▲ ▼ =), `켜짐/꺼짐`만 보여 줍니다. 판정 단어와 상태에 따라 바뀌는 색이 없는지 모의 점검으로 확인했습니다. [AI 확인]
- **오류·경고 건수는 침해나 공격 탐지 결과가 아닙니다.**
- 기록은 이 브라우저의 `localStorage`에만 숫자로 저장되고(최대 10개) 서버나 외부로 보내지 않습니다. 주소·포트별로 따로 저장되어 포트를 바꾸면 보이지 않을 수 있습니다. [소스 확인]
- Windows PowerShell을 쓰는 읽기 도구라 Windows 밖에서는 동작하지 않을 수 있습니다. [미확인]
- 막대 높이는 5% 단위로 반올림해 그립니다. 정확한 값은 막대 아래 숫자입니다. [소스 확인]
